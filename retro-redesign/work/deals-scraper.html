Automation + Affiliate

Deals Scraper

Scrapes deals. Converts links. Broadcasts to Telegram. Zero servers. Zero manual effort.

Situation

Running an affiliate coupon site means your revenue lives and dies on whether users see deals before they expire. DesiDime posts hundreds of deals a day. Manually finding them, converting each link to an affiliate URL, and posting to a Telegram channel wasn't a content strategy — it was a part-time job nobody signed up for. The other problem: affiliate link conversion was a manual step sitting between a good deal and actual revenue. Skip it once, the deal goes out without earning anything.

Task

Build a system that monitors DesiDime for new deals, automatically converts product links to affiliate links via the EarnKaro API, and broadcasts formatted deal alerts to a Telegram channel — without any server, infrastructure cost, or human involvement after setup.

Action

Built entirely on Google Apps Script with a time-driven trigger — no hosting, no backend, no maintenance overhead. Runs every 15–30 minutes on Google's cloud. Pipeline: Fetch (scrapes DesiDime with browser-like user agent), Parse (extracts deal metadata via regex), Dedup (reads Google Sheet log to skip already-posted links), Convert (sends raw link to EarnKaro API for affiliate conversion, falls back to original URL on failure), Broadcast (sends formatted Markdown message to Telegram). Google Sheets handles logging. Sheet auto-trims at 1,000 rows. Open-sourced on GitHub with full setup guide.

Result

  • Fully automated deal-to-Telegram pipeline with zero ongoing manual effort
  • Every deal carries an affiliate link — no missed conversions
  • Fallback mechanism means broadcast never fails even if affiliate API is down
  • Built and shipped independently — architecture, code, and deployment

What I'd Do Differently

Regex-based HTML parsing is brittle — DesiDime changes their structure and the whole extraction breaks. I'd replace it with a proper RSS feed or API integration if one existed, and add an automated alert when the parser starts returning empty results rather than silently failing. Silent failures in a revenue pipeline are the worst kind.
