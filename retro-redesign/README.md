# Portfolio — Akshat Somani

Retro-futuristic personal site. Static HTML — no build step.

## Files

- `index.html` — landing page (hero, 3D centerpiece, flip-card projects, bento nav, footer)
- `app.jsx` — React components for the landing page (loaded via Babel in the browser)
- `tweaks-panel.jsx` — in-design Tweaks panel controls
- `retro.css` — global theme + page styles
- `hero3d.css` — hero 3D scene styles (orb / panel / radar centerpieces)
- `work.html`, `thinking.html`, `about.html` — sub-pages
- `work/` — 4 project case studies (embrace, dumbmoney, earnkaro, deals-scraper)

## Deploy

Static — push to any static host (Vercel, GitHub Pages, Netlify). No build required.
